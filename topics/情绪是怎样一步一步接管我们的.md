# 情绪是怎样一步一步接管我们的？

情绪很少由一个按钮突然开启。这条路线沿着处境、注意、解释、身体、念头、感受、行动与事后循环，帮助你找到情绪从哪里变强，也判断什么时候可以暂停、什么时候应先处理现实安全。

> 这是一条阅读路线，不是人体固定时间线。不同过程可能从不同位置先变化，并迅速互相影响。

## 路线总览

```text
处境与触发 ⇄ 注意捕获
      ⇅           ⇅
评价与解释 ⇄ 身体反应
      ↓
自动思维、主观感受与行动冲动
      ↓
情绪升级 → 实际行动 → 即时回报
      ↘         反刍与下一次触发
```

## 几个关键区别

- **触发不是事件自带的按钮。** 同一线索会因关系、目标、记忆、身体状态和环境获得不同意义。
- **身体参与情绪，却不是情绪条形码。** 心跳、呼吸或肌肉变化不能单独读取完整情绪。
- **念头、感受、冲动和行动不是同一件事。** 念头出现不等于事实，冲动出现也不等于已经选择行动。
- **调节不等于压下情绪。** 合适回应可能是继续观察，也可能是沟通、休息、离开刺激、解决问题或寻求支持。
- **觉察不是完整解决方案。** 当现实危险、严重不适或功能受损存在时，先处理现实。

## 读完后可以怎样使用

回想一次具体事件，依次写下：

1. 当时发生了什么，什么线索最先抓住注意？
2. 我怎样解释它，身体出现了什么变化？
3. 哪些念头、感受和行动冲动随后出现？
4. 我实际做了什么，它带来了什么即时结果？
5. 如果再次发生，哪个位置可以更早发现或调整？
6. 这件事是否涉及现实危险、医疗问题或需要他人支持？

目标不是把情绪拆成标准答案，而是更清楚地看见过程和选择点。
