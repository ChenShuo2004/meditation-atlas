# 专题长路线

四条长路线从真实问题出发，按顺序调用知识节点；正文仍只在节点中维护。

- [情绪是怎样一步一步接管我们的？](./%E6%83%85%E7%BB%AA%E6%98%AF%E6%80%8E%E6%A0%B7%E4%B8%80%E6%AD%A5%E4%B8%80%E6%AD%A5%E6%8E%A5%E7%AE%A1%E6%88%91%E4%BB%AC%E7%9A%84.md) — 情绪很少由一个按钮突然开启。这条路线帮助读者沿着处境、注意、解释、身体、想法、感受、行动与事后循环，找到情绪从哪里变强，也判断什么时候可以暂停、什么时候应先处理现实安全。
- [冥想到底是什么，我该从哪种练习开始？](./%E5%86%A5%E6%83%B3%E5%88%B0%E5%BA%95%E6%98%AF%E4%BB%80%E4%B9%88%EF%BC%8C%E6%88%91%E8%AF%A5%E4%BB%8E%E5%93%AA%E7%A7%8D%E7%BB%83%E4%B9%A0%E5%BC%80%E5%A7%8B.md) — 这条路线不替读者选一个“最好”的冥想，而是把个人意图、练习家族、注意方式、当下状态和安全边界连起来，帮助人选出一个足够具体、可以调整的起点。
- [走神、困倦、烦躁、没感觉，是我练错了吗？](./%E8%B5%B0%E7%A5%9E%E3%80%81%E5%9B%B0%E5%80%A6%E3%80%81%E7%83%A6%E8%BA%81%E3%80%81%E6%B2%A1%E6%84%9F%E8%A7%89%EF%BC%8C%E6%98%AF%E6%88%91%E7%BB%83%E9%94%99%E4%BA%86%E5%90%97.md) — 这些体验有时只是注意和状态的正常波动，有时提示练习方法不匹配，也可能与睡眠、身体、药物、压力或心理健康有关。这条路线不急着判“对错”，而是教读者先分类，再决定继续、调整、停止还是求助。
- [冥想真的有效吗？怎样看懂效果证据？](./%E5%86%A5%E6%83%B3%E7%9C%9F%E7%9A%84%E6%9C%89%E6%95%88%E5%90%97%EF%BC%8C%E6%80%8E%E6%A0%B7%E7%9C%8B%E6%87%82%E6%95%88%E6%9E%9C%E8%AF%81%E6%8D%AE.md) — “冥想有效”不是一个可以脱离结果、人群、比较对象和时间回答的总命题。这条路线帮助读者从一句效果宣传走到一套基本证据判断，并在最后回到个体差异。
