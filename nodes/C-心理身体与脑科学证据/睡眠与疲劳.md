# 睡眠与疲劳

> 节点 `SYS-044` · 区域 C

白天坐下冥想，三分钟后头开始往下点。有人会觉得这是终于放松了，也有人责怪自己不够专注。可如果昨晚只睡了四小时，身体此刻最需要的也许不是更努力保持觉察，而是睡眠。

日常一句“我好累”，常混着两个不同问题。**困倦是保持清醒变难、容易睡着的倾向；疲劳则更接近能量、耐力或继续投入的能力下降。** 两者可以一起出现，也可以分开：人可能疲惫却睡不着，也可能精力感觉尚可，却在单调任务中迅速打瞌睡。

## 困、累和低落，不能只用一个状态词解释

Shen 等对定义和测量的综述指出，困倦与疲劳相关但不同，研究中的量表和客观任务也只捕捉各自的一部分。普通地说，“想睡”“没力气”“不想做”“脑子慢”和“情绪低”可能同时被说成累，却不一定需要同一种处理。

困倦常与睡眠不足、昼夜节律、睡眠质量、药物和睡眠障碍有关；疲劳还可与感染、贫血、疼痛、慢性疾病、过度负荷、药物和心理状态等多种条件相连。这里不是用症状清单自我诊断，而是提醒：一杯咖啡、一次冥想或一句“休息一下”不能替所有原因回答。

低落情绪也可能带来能量和动机下降，但疲劳不等于低落。一个人很想做事却身体撑不住，和人对事情失去兴趣、希望或愉快感，并不是同一条经验。持续变化需要结合时间、睡眠、身体症状、药物与功能一起判断。

## 睡少了，情绪调节也会变难，但不是任何情绪的单一原因

睡眠与情绪会双向影响：担忧、疼痛和高唤醒可以打断睡眠，睡眠不足又可能让注意、情绪反应和调节选择变得更脆弱。Palmer 与 Alfano 的整合综述发现，睡眠受损与情绪过程多个阶段的适应不良变化有关，同时指出既有研究常没有分清情绪产生与真正的调节过程。

所以“我今天特别易怒，可能和缺觉有关”是一个可核对的条件判断；“所有问题都是没睡够”则越过了证据。关系冲突、危险、疾病和长期压力仍然存在。补觉能恢复部分资源，却不能替代处理现实问题。

睡眠时间也不是人人相同的道德标准。比单晚数字更有用的是一段时间的模式：是否有足够睡眠机会，醒后是否恢复，白天是否频繁打瞌睡，工作、驾驶、情绪和基本功能是否受影响。

## 冥想里的困意首先是一条信息

低刺激、闭眼、躺卧和保持不动，本来就可能让睡意更容易被察觉。练习时睡着不证明进入了更深状态，也不必一律算失败。若目标本来就是休息，安全环境里睡着可以只是身体需要；若目标是训练清醒觉察，可以改为睁眼、坐直、站立、行走或换到较清醒的时间。

但练习不能拿来顶替睡眠或强撑危险任务。美国国家公路交通安全管理局提醒，严重缺觉时咖啡也不能可靠防止短暂入睡；困倦时不应以呼吸练习、冷刺激或意志继续驾驶和操作危险设备。

持续明显日间困倦、无法解释的疲劳、睡醒仍不恢复，或伴随响亮鼾声与呼吸停顿、突然肌无力、晕厥、胸痛、发热、体重显著变化及功能下降时，需要合适的医疗评估。冥想可以帮助注意到状态，却不能告诉人疲劳的病因。

## 来源与证据边界

- **提出／课程与大众材料**：`SRC-016、042、082、213、237`。提供困倦、睡眠优先、情绪和练习调整线索；无署名清单、课程解释与固定见效时间不作为病因或疗效证据。
- **定义辨析／睡眠医学综述**：`SRC-397`。支持区分困倦与疲劳，并说明现有主客观测量各有局限；不提供个人病因诊断。
- **睡眠—情绪／整合综述**：`SRC-398`。支持睡眠受损与多个情绪过程相关，同时限制把情绪反应直接等同调节能力或建立单向因果。
- **驾驶风险／官方交通安全资料**：`SRC-399`。支持困倦时不靠咖啡或意志继续危险驾驶；交通安全指导不处理疲劳的临床病因。

本卡把练习中的困意还原成状态信息，而不是冥想深度或意志力评分。
