# 疼痛感觉与第二层反应

> 节点 `SYS-042` · 区域 C

同一个人扭伤脚踝时可能先跑出危险区域，停下来才感到剧痛；伤口已经愈合很久，疼痛也可能继续存在。反过来，一张影像上看到组织变化，并不能告诉旁人这个人此刻究竟有多痛。

**疼痛是一种不愉快的感觉与情绪经验，与实际或潜在组织损伤相关，或类似于这类损伤带来的经验。** 这一定义把疼痛放回个人经验，同时保留身体、心理和社会因素共同影响它的事实。影响不是“想出来的”的同义词。

## 伤害感受不是疼痛的测谎仪

**伤害感受**（nociception）是神经系统对可能损伤组织的刺激进行编码和处理；疼痛则是人或动物实际经历到的不愉快经验。国际疼痛研究协会明确说，两者不同，不能只从感觉神经元活动推断疼痛。

这带来两个同时成立的判断。第一，没有在检查中找到清楚组织损伤，不等于疼痛不存在。疼痛可以在组织愈合后持续，也可能涉及神经系统病变或伤害处理方式改变。第二，疼痛真实也不意味着已经知道病因；不同机制可以并存，仍需病史、检查和必要的医学评估。

疼痛还不只是一个强度数字。刺、烧灼、跳痛、压迫的位置和时间形态属于感觉特征；害怕、厌恶与无助属于情绪经验；它对睡眠、移动、工作、关系与意义的影响又是功能层。把这些层面分开，有助于沟通，却不能把情绪部分删掉以后才承认真痛。

数字量表更适合帮助同一个人追踪变化和沟通处置，不是跨人的疼痛排行榜。一个人报七分、另一个人报四分，不能据此判断谁更坚强、谁的组织损伤更重。疼痛从什么时候开始、怎样波动、什么动作受限以及出现哪些伴随症状，往往比单个数字提供更多照护信息。

## 急性疼痛常在保护，持续疼痛仍然需要照护

新发疼痛可能提醒损伤、感染、缺血或其他急性问题，首要任务是停止伤害、检查原因和获得照护。突然剧烈疼痛，或疼痛伴随胸闷、呼吸困难、晕厥、意识变化、单侧无力、严重外伤、高热等危险信号时，不应先用观察练习测试自己能否接纳。

疼痛持续时间较长时，保护系统也可能变得过于敏感，动作、睡眠、情绪、注意和社会处境彼此影响。说它具有生物—心理—社会维度，是承认完整负担，不是把责任推给患者，也不是让心理练习替代病因评估、药物、康复或其他治疗。

疼痛报告应被尊重。旁人无法凭表情、安静程度、能否工作或是否愿意练习判断疼痛真假；个人也不必把“检查正常”翻译成“我在夸大”。更好的问题是：疼痛怎样变化，哪些功能受限，出现了什么新信号，现有照护是否需要调整。

## 疼痛之后还会出现预测、评价和保护动作

疼痛出现后，脑中可能很快跟上“会永远这样”的预测，身体进一步绷紧，人开始羞耻、自责或避开越来越多活动。这里的**第二层反应**是帮助拆分预测、情绪、注意和行为的实践说法，不是身体里另有一层可单独测量的疼痛。

疼痛灾难化研究描述威胁放大、反复占据注意和无助感的组合，并发现它与疼痛经验和困扰稳定相关。但关联不能变成“因为你想得太负面，所以才痛”。疾病不确定性、治疗失败和不被相信，本来就会让最坏预测更容易出现。

肌肉防护和避免动作也不全是错误。新伤或病因未明时，保护和求医可能正需要；经过评估后，若恐惧让活动范围长期缩小，生活功能才可能进一步受影响。所谓“痛苦＝疼痛＋抗拒”最多是寻找附加环节的比喻，不能用来计算一个人有多少痛是自己制造的。

可分别处理的环节也不同：感觉需要评估和照护，预测可以核对，安全时可减少额外用力，羞耻需要被理解，现实限制需要调整。接纳不是喜欢疼痛或停止治疗，而是承认这一刻疼痛已经存在，再决定止痛、休息、移动、求助或继续重要活动。

## 注意可以改变疼痛经验，但不是取消警报

把注意放到疼痛处，感觉可能变得更细，也可能更强。短时间辨认位置、范围、波动和周围仍不痛的区域，有时能减少“整个我都被痛占满”的感觉；有时却会增加警觉、肌肉防护和恐慌。注意变化说明信息优先级在变，不证明组织被冥想治愈，也不证明疼痛只是评价。

可承受、原因已评估的疼痛，可以尝试短时观察，再主动回到声音、接触点或现实活动。练习是否有用，不只看疼痛分数是否立刻下降，也看是否更能沟通需要、调整动作、休息和参与重要生活。若观察使疼痛快速加剧、出现新症状、让人延误照护或为了“不过度反应”继续伤害，应立即停止。

身体的警报值得听见，疼痛的主观性也值得尊重。二者并不冲突：疼痛是个人经验，但照护从来不该只由个人独自承担。

## 来源与证据边界

- **提出／课程、访谈与自助材料**：`SRC-014、023、162、181、202`。提供疼痛观察、身体扫描与辅助管理线索；课程案例、混合身心解释和研究数字不作为病因或疗效证据。
- **定义修订／国际专家工作组**：`SRC-393—394`。明确疼痛是感觉与情绪经验、疼痛与伤害感受不同、个人报告应被尊重；国际定义不替代具体疾病诊断与处置。
- **评价、注意与疼痛负担／理论综述**：`SRC-395`。支持灾难化与疼痛、困扰之间的关联及多条可能路径；不能证明负面想法单向制造疼痛或用于责怪个人。
- **正念辅助效果／随机试验系统综述与元分析**：`SRC-396`。提示慢性疼痛、抑郁症状和生活质量可能有小幅改善；疼痛证据质量低、安全报告有限，不能承诺消痛或替代多专业照护。

本卡先保护疼痛的真实性与医疗位置，再把可以分别照顾的第二层环节拆开，不把责任推回患者。
