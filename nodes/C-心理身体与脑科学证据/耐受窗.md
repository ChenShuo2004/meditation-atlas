# 耐受窗

> 节点 `SYS-036` · 区域 C

有些不适虽然强烈，人仍能知道自己在哪里、听懂一句话、作出选择；另一些时刻，刺激并没有明显变大，人却已经只能逃、僵住、发空或断开。耐受窗试图描述的不是“情绪应该多平静”，而是当下还有多少整合与行动能力。

**耐受窗是一种临床工作模型：人在某个可承受的激活范围内，仍能接触体验、处理信息并保有一定选择；超出这一范围时，可能朝过度激活或低度激活失稳。** “窗”是帮助观察状态与调整剂量的比喻，不是已经存在统一仪器和阈值的生理区间。

## 在窗内不等于舒服，出窗也不是意志薄弱

一个人可以悲伤、害怕或生气，同时仍知道发生了什么、能听见他人、可以暂停并决定下一步。这可能仍在可工作的范围内。反过来，表面安静也未必表示稳定：发空、反应迟钝、极度困倦、不真实或与环境断开，可能已经很难继续处理信息。

因此，耐受窗不是用平静程度评分，更不能用心率、HRV 或一个身体感觉直接划线。较实用的观察是功能：还能不能定向当下、理解语言、注意到多于一个选项、保持身体与环境的联系，并在需要时停止。

## 窗会随条件改变，不是固定人格容量

睡眠、疼痛、饥饿、疾病、药物、熟悉程度、现实安全、任务意义和是否有人支持，都会改变当下可承受范围。同一个人今天能面对的内容，缺觉或独处时可能承受不了；这说明条件变了，不自动证明能力退步。

关系也会改变窗口的实际表现。一个人独自面对某段记忆时很快失稳，在可信任的人陪伴下却能保持环境联系；这不是前后测出了不同的固定能力，而是共同调节和可用资源变了。把所有变化归因于个人韧性，会漏掉情境本身。

## 这是一个有用但证据身份有限的模型

Corrigan、Fisher 与 Nutt 用耐受窗组织复杂创伤后的自主调节、情绪和行为，并进一步提出多巴胺通路等神经药理假说。这篇综述说明该模型确实进入临床与研究讨论，却不是对一个统一“窗口宽度”的验证；其中大量机制来自理论连接、动物模型和特定创伤人群，不能直接外推所有日常压力或冥想体验。

所以公开表达应把它叫作工作模型，而不是脑科学定律。它可以帮助提出“现在是继续接触、降低剂量，还是先恢复定向”的问题；不能据此诊断创伤、解释所有行为，或宣称某种练习已经把神经系统窗口永久拓宽。

## 练习的重点不是硬撑，而是找到可工作的剂量

练习中若仍能注意身体、环境和选择，可以短暂接触困难体验，再返回较稳定对象。若注意越来越窄、动作冲动压倒选择，或人变得发空、遥远、难以理解引导，应减少刺激：睁眼、移动、缩短时间、换外部锚点、与人连接或停止。

“扩大耐受窗”常被用作长期目标，但不能只凭一次忍得更久判断。忍耐也可能是僵住、压抑或失去感觉。更可靠的变化包括：较早发现失稳、能调节剂量、较快重新定向、拥有更多现实选择，以及不再把停止练习视为失败。

危险、急性医疗问题、持续解离、反复惊恐、自伤或功能明显受损，需要现实与专业支持。耐受窗语言可以协助沟通，不能替代风险评估和治疗。

## 来源与证据边界

- **提出／课程与实践材料**：`SRC-088、266—267`。提供高低激活、剂量和可退出线索；课程中的固定神经解释与忍耐叙事不直接采用。
- **耐受窗与复杂创伤／理论综述**：`SRC-385`。证明该模型存在于临床研究讨论，并提出自主与神经药理解释；不构成统一阈值、普遍脑机制或个人诊断验证。
- **现实安全与支持／机构指导**：`SRC-290、293`。限制把内部练习置于危险、基本需要与现实行动之前；不是耐受窗量表或疗效试验。

本卡保留模型的实践价值，同时明确它不是可以被手表测出的生理窗口。
