# 急性与慢性压力

> 节点 `SYS-034` · 区域 C

演讲开始前十分钟，心跳变快、手心出汗、脑中不断预演；真正站上台后，注意反而集中起来。事情结束，身体又过了一阵才慢慢回落。这里发生的不是一个瞬间的“压力值”，而是一段有预期、有动员、也需要恢复的过程。

**急性压力是围绕近期、突发或有明确时点的要求，在相对短时间内形成的身心适应过程；慢性压力则来自压力源持续或反复出现，而恢复机会、资源补充或现实解决长期不足。** 两者描述的是时间与恢复条件，不是轻重等级；慢性压力也不等于急性反应永远停在峰值。

## 身体动员不自动证明事件有害

运动、比赛、公开表达、赶车和突发危险都可能让心率、血压、呼吸、出汗或激素发生变化。Koolhaas 等人对压力概念的批判指出，奖励性或主动追求的活动也可能产生很大的生理反应，所以仅凭反应幅度，无法判断经历是负面压力还是有意义的挑战。

他们主张把不可预测、不可控制和超出自然调节能力看作更关键的压力条件。这个较窄定义不是领域唯一标准，却提醒人：身体“启动了”不等于系统受损。是否有威胁、能否预期、有没有选择、需要付出什么、结束后能否恢复，都比一个峰值更有解释力。

急性压力也不等同恐惧或焦虑。恐惧聚焦当下危险，焦虑常围绕不确定威胁；急性压力可以包含它们，也可以表现为专注、兴奋、愤怒、空白、僵住或迅速行动。人的主观体验与心率、皮质醇等指标还可能不同步。

## 起点、峰值和恢复都要看

研究一次急性压力，通常需要说明压力源是什么、何时开始、持续多久、测量发生在预期、任务还是恢复阶段。Crosswell 等人的压力测量建议区分压力源暴露、主观评价、情绪和认知反应、行为以及生理指标，并把它们放回个人历史与当下情境。

这意味着“练习后皮质醇更低”若没有采样时点，就难以解释。HPA 轴反应具有延迟；心率又可能更快变化。基线不同、提前知道任务与否、练习是否发生在峰值前后，都会改变结果。只比较一个前后点，可能错过反应速度和恢复轨迹。

恢复并不是立刻回到某个标准数字。事件结束后继续发抖、疲惫、反复回想或需要安静一会儿，可以是反应尚在回落；若危险仍在、后果还需处理或下一个要求马上到来，恢复条件本身就没有出现。

## 慢性负荷不是一条持续高位的直线

长期照护、疾病、账单、危险关系和随时待命的工作，都可能让要求很久没有真正结束；许多短事件若密集重复、不可预测，或每次发生前都要持续戒备，也会形成长期负荷。反过来，一项长期任务若可控制、有支持、能休息且有明确意义，未必产生相同结果。

慢性压力因此不能只按日历天数或一次皮质醇判断。需要同时看暴露频率、可控性、资源、睡眠、角色冲突、社会支持和反应能否回落。贫困、歧视、疾病、照护和工作制度也是压力条件，不能被缩成个人心态。

McEwen 用**稳态负荷**组织长期适应的累积代价：自主、内分泌、免疫、代谢和行为变化短期可以保护人，反复启动、无法关闭、反应不足或系统失配时，长期代价可能增加。这个概念不是可由手表或一次化验读出的“压力桶”，不同研究的组合指标与阈值也不统一。

## 当下最需要的动作取决于任务是否还在

真正危险时，先离开、求助、急救或完成必要行动。即将考试、演讲或比赛时，目标也不一定是把所有激活压下去，而是保留足够行动能力，减少无用的额外消耗。事件已经结束时，补水、进食、移动、休息、与人联系或处理后续问题，可能比继续分析身体更直接。

冥想和呼吸可以帮助部分人发现注意过度收窄、减少重复预演或支持恢复，但不是每个阶段都合适。闭眼向内若放大心悸、窒息、闪回或不真实感，应睁眼、外部定向、移动或停止。强烈反应持续不退、反复发生、明显影响睡眠与功能，或伴随医疗风险时，需要进一步评估，不能把所有后续反应都称作一次普通急性压力。

## 来源与证据边界

- **提出／课程与大众综合**：`SRC-028、046、088`。提供高唤醒、行动与短时调节线索；不能仅凭身体强度判断压力性质。
- **多层压力测量／方法综述**：`SRC-305、382`。要求区分暴露、评价、反应、时间与情境；测量框架不能替代个人风险判断。
- **压力定义争议／批判性综述**：`SRC-384`。强调不可预测、不可控制与恢复受阻，并显示生理动员不等于负面事件；其较窄定义不是唯一共识。
- **长期适应与累积代价／生理综述**：`SRC-383`。说明压力介质短期可保护、长期可能形成多种代价；稳态负荷是研究框架，不是个人自测诊断。

本卡不把正常挑战反应病理化，也不把长期负荷个人化或承诺靠一次练习逆转。
