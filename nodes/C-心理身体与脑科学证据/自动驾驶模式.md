# 自动驾驶模式

> 节点 `SYS-008` · 过程与机制 · 深入节点 L2

回过神时，人已经走到家门口，却几乎想不起沿途看见了什么。路并不是完全没走，动作也不是完全失控；只是熟悉序列在很少持续监测的情况下完成了。

**自动驾驶模式是正念教学里的简称，描述行为、念头或反应以较少当下觉察和有意选择继续运行。** 它不是正式诊断，也不是大脑真的切换到一个单独模式。熟练动作、习惯反应、注意转移和缺少元觉察，都可能产生相似体验。

## “自动”不是一个开关

Moors 与 De Houwer 的概念综述指出，研究者说一个过程自动，可能分别指它没有意图、难以控制、不依赖当前目标、由刺激触发、不进入意识、速度快或占用资源少。这些特征可以分开出现，不应该合成一个全有或全无的标签。

开熟悉的门可能快速省力，却仍可随时停下；一句自我批评可能未经邀请出现，但被发现后不一定无法控制；习惯性刷手机可能由线索启动，同时也服务着短时缓解的目标。把它们都叫“自动驾驶”有助于日常识别，却不能替代具体分析。

自动性本身也不是敌人。走路、打字和完成熟练步骤若每次都要逐项思考，生活会变得极其缓慢。问题通常出在环境已经改变，旧序列仍继续；行为与当前意图冲突，却很久没有被发现；或者即时结果不断强化一项正在缩小生活选择的习惯。

## 觉察不是接管每个动作

从自动运行里醒来，不等于以后必须全程手动控制。**元觉察**是知道自己的注意和心理活动此刻在怎样变化。它可能只带来一个很短的发现：“我又打开了应用”“我正在用同一句话骂自己”“我没听见对方后半段”。有了发现，才可能检查这条序列现在是否仍合适。

正念练习常用吃饭、走路或洗澡来观察自动性，但目的不是让每个感官细节永远保持清晰。过度监控熟练动作可能反而增加负担。更实际的是在容易产生后果的节点恢复选择：发送之前、攻击之前、继续刷之前，或发现自己已经离开当前对话时。

自动驾驶也不能和失去意识、记忆异常或解离混为一谈。如果出现明显时间缺失、无法解释的行为、现实感改变、驾驶安全问题或其他功能损害，不能仅用“我太不正念了”解释，需要评估具体的睡眠、药物、身体或心理因素。

## 来源与证据边界

- **提出／课程与方案材料**：相关材料。提供自动反应、日常活动和短暂停顿语言；教学比喻不能作为单一脑模式证据。
- **拆分自动性／理论与概念综述**：相关材料。说明无意图、无意识、快速、省力、刺激驱动与难控制等特征应分别考察；不提供个人测量或正念疗效结论。
