# 战斗／逃跑／僵住反应

> 节点 `SYS-039` · 区域 C

有人在冲突里声音突然变大，有人立刻想离开，也有人脑中一片空白、身体动不了。事后，人很容易把这些反应解释成性格：我太暴躁、太软弱，或者当时没有反抗就是默许。威胁发生时，身体却不一定等到人想清楚才组织行动。

**战斗、逃跑和僵住是感到威胁时可能出现的防御反应：身体、注意和动作被重新组织，以便抵抗、离开、暂停行动或继续收集信息。** 它们是反应方向，不是三种人格，也不是每个人都会依次经过的固定程序。

## 僵住不是“什么都没做”

动物与人类研究把僵住描述为动作受到抑制、心率可能减慢，同时感知和行动准备增强的状态。普通地说，人看起来不动，系统却可能正在紧密监测：危险从哪里来，现在动会不会更糟，什么时候才有机会逃开。Roelofs 因而把它称作“为行动而冻结”，而不是纯粹关机。

这也解释了为什么外表与内部状态可能相反。一个人站着不动、说不出话，内部警觉仍可能很高；另一个人则可能在不可逃的处境里出现更明显的无力、倒下或意识变化。把所有静止都叫作副交感关闭，或把僵住简单放在低唤醒一端，会压平不同反应。

防御级联模型还区分定向、僵住、逃跑／战斗、强直性不动等阶段。但它主要整合动物、实验室与临床材料，具体神经图式并没有被验证成每个人都照着运行的路线图。真实处境中，人可以一边顺从一边寻找出口，也可以先反击、随后僵住；距离、可逃性、过往学习、身体条件和是否有人支持都会改变反应。

## 反应有保护功能，不代表当下判断一定准确

身体发出警报，说明它正在处理潜在代价，不等于危险已经被完整确认。门突然关上、熟悉的人语气改变、过去创伤的相似线索，都可能迅速调动防御；有时确有危险，有时系统使用了不完整或旧的信息。

判断的顺序不能反过来。处境仍危险时，离开、呼救、抵抗、寻找掩护或顺势保全自己，都可能是合理行动，不能先要求放松。安全以后，若同类反应反复在无威胁情境中启动、很难更新，才需要帮助身体重新区分“当时”和“现在”。

同样，看到一次退缩、发火或僵住，也不能诊断创伤，更不能从动作读取完整恐惧。防御行为、身体变化和本人有意识感到害怕是相互作用的层面，不是同一个指标。“讨好”常被流行内容列为第四种反应，它可以描述以顺从、安抚来降低关系危险的行为，但目前不宜与实验研究中的战斗、逃跑、僵住并列成已验证的固定神经类别。

## 安全之后，重点是把选择还回来

反应正在发生时，长篇分析通常没有用。先看环境、出口和可用的人，再用短而具体的信息：说出所在地点和日期，感受脚与地面的接触，允许移动，减少围观和追问。若闭眼、细察心跳或控制呼吸让警报更强，可以睁眼转向外部，不把坚持静坐当作调节成功。

事后也不必急着逼问“为什么没反抗”。更有帮助的是重建当时的约束：危险有多近，是否能逃，权力差异是什么，身体做了什么来争取生存。能较早认出反应、核对当下安全、获得更多行动选项，比把自己训练成永远不僵住更现实。

如果防御反应频繁重现，伴随闪回、记忆断片、现实感改变、持续回避、睡眠破坏或功能受损，需要创伤知情的专业评估。练习可以协助定向和恢复选择，不能替代安全计划、医疗照护或创伤治疗。

## 来源与证据边界

- **提出／课程与大众学术材料**：`SRC-088`。提供战斗、逃跑、僵住与创伤知情练习线索；作者模型不直接作为固定神经顺序或个人诊断。
- **扩展／动物—人类转化综述**：`SRC-386`。支持僵住可伴随动作抑制、心率减慢、感知与行动准备；人类证据仍有限，动物回路不能直接解释个人经历。
- **限制／防御级联临床综述**：`SRC-387`。区分多种防御形态及其转换；其“硬连线”与特定神经图式是整合模型，不作为人人相同的确定路线。
