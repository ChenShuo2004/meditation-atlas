# 持续注意

> 节点 `SYS-003` · 区域 C

看一分钟表格不难。困难的是看了二十分钟以后，仍能发现刚出现的那个异常数字。任务没有变，注意的质量却会随时间、疲劳、刺激频率和动机一起变化。

**持续注意是在一段时间内保持对当前任务的准备与监测，使需要处理的信号出现时仍能发现并回应。** 它不等于眼睛一直看着，也不要求每一秒同样专注。人可能姿势没动，注意早已离开；也可能短暂走神后返回，仍完成了较长时间的目标维持。

## 要维持的不是用力感，而是任务规则

Sarter 等人的综述把持续注意描述为长时间准备发现少见、不可预测信号的能力。很多实验因此使用持续监测任务：大部分时间没有事件，目标偶尔出现。这样的研究适合观察时间带来的漏报和反应变化，却不等于阅读、创作、对话和冥想都共享同一种难度。

持续注意还受目标和刺激共同影响。当前要找什么需要被维持，信号出现时又要从背景中取得优先级。综述讨论了人类影像和动物神经研究，但早期脑区与神经递质框架不能直接用于判断个人为什么不专心，也不能把任务表现差归结为某一处大脑失灵。

## 注意随时间波动，不等于某一刻突然“用完了”

持续任务里的表现往往会起伏：一段时间稳定，随后漏掉几个信号，短暂休息后又恢复。研究者会用漏报、反应时和表现随时间下降等指标描述这种变化，但这些指标不能单独告诉我们原因。目标价值变低、身体疲劳、刺激太少、担忧占据处理，或者环境反复打断，都可能产生相似结果。

这也是“注意力只有多少分钟”很难成为通用答案的原因。看熟悉影片、校对陌生数字和守候极少出现的警报，信号密度与反馈完全不同；有无睡眠、任务是否自愿、出错代价多大，也会改变维持方式。一个实验任务得到的平均时长，不能变成所有人学习或冥想的倒计时。

日常里，注意变差未必是意志突然耗尽。睡眠不足、疼痛、压力、任务太单调、目标不清或环境频繁中断，都可能改变维持条件。持续盯着却越来越多错误，可能说明该休息、换任务结构或减少输入，而不是继续增加用力。

## 走神以后回来，也是持续注意的一部分

专注练习常把“没有走神多久”当成绩，但走神本身并不能单独衡量持续注意。真正的练习循环还包括发现偏离、重新选择对象和继续维持。一次十分钟练习中多次回来，不等于十分钟全都失败；它同时暴露了维持会波动，也提供了重新进入任务的机会。

持续注意与专注也不是同一个词。专注描述围绕一个对象组织注意的方式，持续注意特别强调这种目标和监测能否跨时间保留。开放觉察同样需要某种持续性：不是一直抓住单一对象，而是维持对经验变化的监测意图。

练习时长不能从研究任务直接换算。更长可能增加训练机会，也可能让疲劳、麻木和机械坚持占据过程。若只记录“坐满了多久”，闭眼坚持和真正维持目标会被混在一起。

比较有用的问题不是“我能撑多久”，而是：多久以后偏离明显增加，我是否还能发现，短暂恢复能否改善，任务是否仍值得维持。持续注意不是把波动消灭，而是让目标在时间里仍有机会被重新找回。

## 来源与证据边界

- **提出／课程与研究综合**：`SRC-068、097、110、237`。提供专注、返回和注意训练线索；课程与大众研究综合不能规定训练时长或统一机制。
- **定义与限制／认知神经科学综述**：`SRC-348`。以长时间准备发现少见信号界定持续注意，并整合早期人类与动物研究；实验范式和神经框架不能直接解释个人日常分心或诊断注意问题。

持续注意不是把自己钉在对象上，而是让任务目标在时间里仍然可被找回。
