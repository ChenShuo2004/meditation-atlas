# MBCT／正念认知疗法

> 节点 `MED-029` · 区域 B

抑郁缓解以后，人可能已经重新工作和生活，心里却仍在监视每一次疲惫：今天不想见人，是不是又要复发？一段低落、一夜失眠或一句自责，很快会把注意带回熟悉的反刍路线。

**MBCT 是 Mindfulness-Based Cognitive Therapy 的缩写，通常译作正念认知疗法。它把正念练习与认知疗法的抑郁复发理解结合起来，最初主要为反复抑郁缓解期的复发预防而发展。** 它不是“用正念把负面想法改成正面想法”，也不等于所有加入呼吸练习的认知行为治疗。

## 它处理的是旧模式怎样重新接管

MBCT 关注一个常见风险：轻微低落出现时，过去与抑郁相连的自责、绝望、身体退缩和反刍可能被整组重新激活。人的第一反应往往是继续分析“我为什么又这样”，结果让情绪和思考缠得更紧。

课程中的身体扫描、坐姿练习、正念运动和三分钟呼吸空间，不负责证明念头错误，而是帮助人较早辨认：低落正在出现，脑中开始重复旧解释，我还可以怎样回应。认知疗法部分则提供抑郁模式、预警信号、活动与情绪、复发计划等理解。**去中心化**——把念头看作正在发生的心理事件，而不是必须服从的事实——是其中一个重要过程，但不能独自代表整套 MBCT。

因此，三分钟呼吸空间可以从课程中单独学到，却不能因为做过它就说自己接受了 MBCT。完整方案还包含八周递进、小组学习、家庭练习、困难探索、认知理解和个体化的复发行动计划。

## 它和 MBSR 相连，却不是换了名字

MBCT 借用了 MBSR 的八周小组形式和多种正念练习，同时加入针对抑郁复发的认知框架。两者都重视体验式学习和家庭练习，但主要人群、课程主题和临床目标不同。把 MBSR 的一般压力语言直接替换成“抑郁”，或把 MBCT 向所有焦虑、强迫、创伤与日常不开心外推，都会丢失方案身份。

现有工作手册也有不同版本。Teasdale、Williams 与 Segal 的自助书能呈现课程练习和理解方式，但一本书无法复制治疗师评估、小组反馈和危机处理。面向一般读者的八周衍生方案又进一步改变了练习时长、人群与临床定位，不能与复发预防治疗证据混用。

## 指南支持的是特定处境，不是一个万能标签

英国 NICE 现行成人抑郁指南把团体 CBT 或 MBCT 列为部分已经缓解、复发风险较高者可讨论的复发预防选择，通常为两至三个月内八次课程，并强调共同决策、预警信号与维持计划。指南没有说所有当前抑郁发作都应先做 MBCT，也没有要求人自行停用抗抑郁药。

Kuyken 等人的个体数据元分析汇总九项随机试验、1,258 名反复抑郁参与者，观察到 MBCT 在约六十周内与较低复发风险相关；与主动治疗比较时差异较小。研究对象主要是反复抑郁、处于完全或部分缓解的人，不能直接转给首次低落、双相障碍、急性自杀风险或其他诊断。

正在经历严重抑郁、明显功能下降、自伤／自杀想法、躁狂或混合状态时，需要临床评估和现实支持。向内练习若增加反刍、麻木、闪回或失去现实感，应及时调整或停止。MBCT 可以是一套治疗与复发预防方案，但它不能替一个人决定诊断、药物和当前最安全的治疗顺序。

## 来源与证据边界

- **提出／课程介绍与完整工作手册**：`SRC-057、098、236、241`。提供 MBCT 的八周结构、练习与认知框架；商业说明、临床手册和大众自助衍生版不能累计为相同临床证据。
- **当前临床边界／官方指南**：`SRC-424`。支持在特定成人抑郁缓解与高复发风险处境中讨论 MBCT，并要求共同决策和复发计划；不能用于个人自诊或自行停药。
- **复发预防／个体数据元分析**：`SRC-425`。汇总反复抑郁随机试验并限制到相应人群和随访期；群体结果不能预测个人一定不复发。
- **组件判断／拆解研究综述**：`SRC-431`。显示现有研究尚不能把完整方案效果稳定分配给某一个组件。

本卡把 MBCT 放回反复抑郁的治疗语境，不让“三分钟呼吸空间”替整套临床方案承担证据。
