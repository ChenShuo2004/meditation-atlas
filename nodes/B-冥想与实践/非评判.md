# 非评判

> 节点 `EXP-030` · 练习条件与困难 · 深入节点 L2

刚发现自己走神，脑中立刻出现一句“我怎么又失败了”；身体有些不舒服，又马上判断“这不应该发生”。经验本身之外，我们常常会迅速加上一层好坏、喜欢或不喜欢的评价。

**非评判不是让判断消失，而是先觉察评价正在发生，不急着被它带着反应。** 它为看清经验、补充信息和决定下一步留出一点空间。

## 它不是什么

- 不是不辨是非，也不是取消价值判断。
- 不是接受伤害、危险或不公平而不行动。
- 不是把所有不舒服都解释成“我太爱评判”。
- 不是强迫自己对任何经验保持平静、中立或喜欢。
- 不是禁止脑中出现“好／坏”“想要／不想要”的自动评价。

真正练习的是：评价出现以后，能否先看见它，而不是立刻把它当成事实或命令。

## 在走神时怎样发生

```text
发现走神
→ 出现“我做不好”的评价
→ 觉察这也是一个正在发生的念头
→ 不继续责备，也不强行消灭评价
→ 返回锚点或根据状态调整
```

非评判并不要求删掉第二步。它关注的是第三步之后，人是否还有别的回应可能。

## 一个简单观察

练习中遇到声音、身体感觉、情绪或走神时，可以问一句：“我刚才自动把它判成了什么？”只确认喜欢、不喜欢、担心或责备，不需要把判断改成正面评价。随后再依据现实决定继续、调整或行动。

若面对现实伤害、安全问题或需要作出决定，非评判只帮助看清反应，不替代边界、求助和判断。

## 来源与边界

- **提出／作者教学**：相关材料。卡巴金把 non-judging 列为正念练习态度，明确它不是“不会判断”，而是觉察判断并减少被喜欢／不喜欢自动束缚。它首先是教学原则，不是已经单独验证的效果机制。
- **扩展／具体练习**：相关材料。中文引导把声音、身体感觉、情绪和走神中的喜欢／不喜欢作为观察对象；该系列与 Headspace 内容簇高度同源，不能累计为独立证据。
- **加强／走神关系**：相关材料。教师引导反复要求发现走神后不责备自己，再回到锚点。
- **限制**：相关材料。非评判、接纳和信任都不等于忽视危险、放弃现实判断或被动忍受伤害。
