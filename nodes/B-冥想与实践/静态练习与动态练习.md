# 静态练习与动态练习

> 节点 `MED-047` · 基础概念 · 深入节点 L2

坐不住时去走路，不一定是逃避；身体安静地坐着，也不等于内在已经平静。“静态更深、动态更浅”的排列，把动作幅度误当成了练习质量。

**静态与动态描述的是外显动作这一个维度。** 静态练习以坐、卧或相对稳定的站姿为主要载体；动态练习把走路、重心转移、伸展或连续动作纳入注意对象。它们都可能是正式练习，也都可能在日常活动中短暂发生。

## 身体并没有真正静止

静坐仍有呼吸、心跳、姿势微调和肌肉张力；行走也可以在稳定而细致的注意中进行。因此，更准确的问题不是“有没有动”，而是：动作是不是练习结构的一部分，注意放在哪里，环境要求什么，以及当前身体能否安全承受。

早期佛教经文把行、住、坐、卧都列入身体觉察，说明静坐不是传统练习的唯一姿势。现代“动作型具身沉思练习”论文则尝试为瑜伽、气功和身心教育等实践建立研究框架。它是一篇概念论文，能帮助定义研究对象，不能证明这些传统具有同一种机制或效果。

## 用状态选择，不按等级选择

静态练习减少外部动作要求，便于观察较细的呼吸、声音、身体感觉或念头；但疼痛、躁动、困倦和内部关注不适时，它也可能变得难以承受。

动态练习增加肌肉、关节、重心和接触变化，可能让注意更容易落在身体与环境上。它也会带来平衡、跌倒、疼痛和环境碰撞风险，并不天然比静坐更“落地”。有些人高唤醒时需要先做缓慢、可控的动作再坐下；有些人活动会进一步升高唤醒，反而更适合坐稳、睁眼和外部定向。

一个简短选择顺序是：

1. 先看安全：地面、视线、平衡、疼痛、交通和是否正在操作设备。
2. 再看状态：困倦、躁动、僵住、呼吸不适或内部注意过强。
3. 选短时版本：坐、站或慢走一两分钟，观察功能变化。
4. 如果更乱、更痛、更恍惚，就调整动作、换外部锚点或停止。

动作不是把情绪甩掉，静止也不是必须忍到安静。选择的标准是当下是否更能感知、判断和行动，而不是哪一种看起来更像冥想。

## 与其他节点为什么相连

| 相关节点 | 为什么相连 | 关系 |
|---|---|---|
| 冥想与多轴分类（MED-001） | 静态／动态只是动作幅度轴，不能代替注意方式、目标、传统、支持与练习情境等其他轴。 | 组成 |
| 正式练习与日常正念（MED-014） | 静态／动态描述动作幅度，正式／日常描述练习场景；坐、走或生活动作都可能进入不同场景，不能用动作方式判断是否正式。 | 区别 |
| 高唤醒与低唤醒（SYS-037） | 困倦、躁动或僵住会改变静止与动作的可承受度，需要用短时反馈选择而非固定配方。 | 策略 |
| 身体感觉：内感受与本体感觉（SYS-025） | 重心、关节位置和肌肉变化为动态练习提供注意信息，但本体感觉不是其唯一机制。 | mechanism |
| 行走冥想（PRA-020） | 行走冥想把连续移动作为练习结构，是动态练习的具体例子，但动态并不代表更浅或更安全。 | 例子 |
| 正念运动／瑜伽练习（PRA-021） | 正念运动把伸展、重心和连续动作纳入观察，是动态练习的一种，不代表所有运动都是冥想。 | 例子 |
| 日常活动觉察（PRA-024） | 生活动作可以承接动态觉察，但练习依附现实任务，不等于一段正式动作冥想。 | 例子 |
| 烦躁与坐立不安（EXP-012） | 静止加重激活时可转向行走或温和动作，动态形式仍能保留觉察。 | adaptation |

## 来源与证据边界

- **动作型具身沉思概念论文**：相关材料。讨论瑜伽、气功与身心实践中的动作、具身和沉思，支持把动作作为独立分类维度；概念框架不证明统一疗效。
- **传统姿势文本**：相关材料。MN 10 把行、住、坐、卧与日常动作纳入觉察；经典中的修行安排不能直接推出当代临床适配。
- **机构动作说明**：相关材料。NHS 的 MBSR 材料给出坐姿、接触、缓慢行走、重心转移和不过度推动身体的实际示范；教学材料证明动作版本存在，不证明适合所有人。
- **既有动作与状态材料**：相关材料。提供行走、瑜伽、先动后静与状态匹配的多种教师版本，其中经验性配方不升级为普遍机制。
