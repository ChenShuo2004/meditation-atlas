# 念头标记

> 节点 `PRA-011` · 具体练习 · 深入节点 L2

“他肯定看不起我”出现时，内容很容易直接变成现实。加上一个很短的标记——“判断”“担心”“回想”——并没有证明它是假的，却先说明：这里有一项心理活动正在发生。

**念头标记，是用一个简短、可修改的词，指出当前念头的形式或过程。** 它通常标记“计划、回忆、预测、自责、分析”，而不是重新讲述整段内容。

## 标记一下，然后看下一步

1. 先发现自己正在跟随一句话、画面、记忆或预测。
2. 选一个宽而短的词，例如“想法”“计划”“担心”。
3. 不争论标签是否完美，也不重复念到内容消失。
4. 回到原锚点、继续开放观察，或处理念头指向的现实任务。

标签太细会变成分类考试；标签太带结论，如“妄想”“负能量”“不该想”，又会把评价伪装成观察。一个暂时够用的词比精确诊断更合适。

## 标记改变的是位置，不是事实

去中心化研究把“从经验内部转向观察这项经验”视为一种元认知变化。念头标记可能为这一步提供语言支架，但批判性综述并没有证明必须标记，或某个词会自动产生距离。

“担心”仍可能指向真实风险；“计划”可能需要记下来执行；“自责”也可能包含需要负责的事实。标记之后仍要核对内容、情境和行动。把所有念头都叫作“只是想法”，会从观察滑向否认。

反刍中可以标记“又在分析”，再问这一轮是否产生新信息。若标记本身变成不停监控、强迫纠正或另一层自我批评，就拿掉标签，换外部锚点、动作或现实问题解决。严重低落、功能受损和伤害风险也不能靠标记独自处理。

## 来源与边界

- **去中心化批判性综述**：相关材料。支持把心理内容作为经验观察的元认知过程；整合模型不是标记练习的直接效果试验。
- **课程与引导材料**：相关材料。提供“想法、计划、担心、分析”等教学版本；同源课程和教师解释不能证明统一机制。
- **事实与行动边界**：相关材料。提醒观察后仍需处理现实伤害、问题与价值行动，不把去黏连写成取消事实。
