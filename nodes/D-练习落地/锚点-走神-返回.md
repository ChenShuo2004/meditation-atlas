# 锚点—走神—返回

> 节点 `PRA-001` · 区域 D

很多人以为练习的目标是一直盯住呼吸。真正反复发生的，往往是另一条循环：先选择一个对象，注意漂走，发现漂走，再重新选择。

**锚点—走神—返回，是专注类冥想中常见的基础练习循环。** 锚点给注意一个当前方向；走神暴露注意已经偏离；发现之后的返回，让人重新落实原来的练习意图。

```text
选择锚点 → 暂时停留 → 走神 → 发现 → 返回或调整
```

## 具体怎样做

1. 选择此刻相对清楚、能够承受的对象，例如鼻端呼吸、腹部起伏、声音、脚底或身体与椅子的接触。
2. 不要求锁死注意，只尝试知道这个对象正在怎样变化。
3. 发现自己开始计划、回忆或跟随一串念头时，先确认“注意离开了”。
4. 不追赶刚才的内容，也不强行把它赶走，把注意轻轻放回锚点。
5. 如果锚点不清楚或明显加重不适，调整对象、睁眼、缩短或停止，而不是把所有困难解释成意志力不足。

返回不是把注意“拽回来”，也不是保证下一秒不再走神。一次练习里重复许多次是正常结构。

## 什么时候它不适用

- 开放觉察练习可能不要求反复回到单一对象，而是观察不同经验出现和离开。
- 呼吸引发明显不适时，不应把呼吸规定为唯一锚点。
- 疼痛、困倦、高唤醒或低唤醒可能需要姿势、时长或练习类型调整。
- 持续恐慌、解离、异常体验或功能受损时，安全与现实支持优先于继续练习。

## 证据与边界

卡巴金课程、Headspace 派生引导、上座部内观入门著作和多份教师材料都能追溯到这一教学循环，因此可以确认它是一种广泛出现的练习结构。

但“广泛采用”不等于已经证明它会普遍改善注意力、情绪或脑结构。`SRC-275` 用 14 名冥想者的按键报告和 fMRI 把专注练习分析为走神、发现、切换和维持四个时段，说明这条循环可以被操作化研究；它没有检验这套动作是否对普通初学者有效。`SRC-273` 观察到 MBSR 组定向表现变化，并推测反复接合、移动和脱离注意可能与此有关，但作者也明确承认这种跨任务迁移仍是推测。

## 来源与版本

- **提出**：`SRC-001、003、011、068`。初学材料反复出现选择呼吸、发现走神、返回的基础动作；其中混合汇编和教师短视频主要证明教学方式。
- **扩展**：`SRC-154、170—172`。完整引导补充姿势、接触点、自然呼吸、计数、发现和非评判返回；中文课程与 Headspace 内容高度同源，不累计为独立证据。
- **研究操作化**：`SRC-273、275`。分别把注意定向变化与四阶段练习循环带入行为和 fMRI 研究；研究设计不足以证明统一疗效、最佳动作或固定脑区机制。
- **传统版本**：`SRC-238`。上座部内观入门著作把分心和返回放在更完整的传统训练语境中，不能与现代健康目标直接互换。
- **限制**：`SRC-088、239—240`。内部关注、身体扫描和呼吸并非在所有状态下都适合，需保留替代锚点与停止边界。

本卡当前确认的是练习结构，不宣称统一疗效。
